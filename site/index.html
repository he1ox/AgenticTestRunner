§ 01 · watch it test

Every verdict
comes with proof.

For each expected result the Test Agent decides to take a screenshot and marks what it checked: boxes, arrows, numbered steps, blur for personal data. Up to three agents test different flows of the same app at once, each in its own isolated browser.

§ 04 · replays, CI and export

$0

per replay. Every case you approve is saved as a script that replays later in its own headless browser, with no agent and no tokens. Same steps, same marked screenshots, same recording.

# gate the merge: exits 1 when a case fails

node qa-runs.mjs suite run smoke --ci --junit qa-junit.xml

# own the tests as code

node qa-runs.mjs export --tag smoke --out e2e/qa

npx playwright test --grep @smoke

When the UI changes on purpose, Repair with agent re-records only that case.

§ 06 · install

One command for any agent.

Or install the plugin for your agent, which also registers the browser. Pick one, not both, or every skill shows up twice.

npx skills add he1ox/AgenticTestRunner

Detects your agents and installs the four skills for each. Then ask your agent to “set up qa-runner” to register the browser once.

claude plugin marketplace add he1ox/AgenticTestRunner
claude plugin install qa-runner@AgenticTestRunner

Adds the 3-browser pool, dedicated Test Agents and model routing per tier. Restart Claude Code so the skills load.

codex plugin marketplace add he1ox/AgenticTestRunner

Then install qa-runner from /plugins.

copilot plugin install he1ox/AgenticTestRunner
gemini extensions install https://github.com/he1ox/AgenticTestRunner
