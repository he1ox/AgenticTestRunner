# Getting help

- **How do I…?** Start with the [README](README.md) and the skill you are using in
  [`skills/`](skills). Run `node <skills>/run-test-plan/scripts/qa-runs.mjs doctor` in your
  project: it checks your setup and says what is missing.
- **Questions and ideas**: [GitHub Discussions](https://github.com/he1ox/AgenticTestRunner/discussions).
- **Bugs**: [open a bug report](https://github.com/he1ox/AgenticTestRunner/issues/new?template=bug_report.yml).
- **Security problems**: privately, as described in [SECURITY.md](SECURITY.md).

qa-runner is maintained by volunteers in their spare time, so there is no guaranteed response
time. A small plan or command that reproduces your problem gets the fastest answer.
